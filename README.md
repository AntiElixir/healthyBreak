# 休息一下～25分钟 healthyBreak 提醒

一个用来提醒自己喝水、起身活动的 Chrome 插件。每 25 分钟弹一次通知，顺便养一只会喝水长大、会累倒的小鸭子。

## 为什么做这个

常常~~学习~~刷视频/玩电脑好久也不休息，起身发现眼球干涩、身体僵硬、口干舌燥、颈椎酸痛……

## 功能

- **标签角标计时**：浏览器右上角实时显示距离上次休息过了多少分钟
- **超时告警**：超过 25 分钟没处理，角标变红并显示 `sos`
- **到点通知**：通知里列出这一轮该做的事——💧喝一口水、🙆伸个懒腰、🚶起身走走、👀眺望远处、🔄转转眼球；点「等会儿」或不理会，下个周期还会再弹
- **昼夜切换**：点击太阳进入「大魔法让时间停止」模式，暂停计时并换成夜景配色
- **养鸭玩法**：本质上是个养成小游戏——按时点刷新休息，小鸭子会变大；一直拖着不处理，它会变小甚至累倒

## 使用

1. 打开 Edge/Chrome，访问 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库根目录
4. 装好之后就等着小鸭子提醒你喝水吧

> 插件基于 Manifest V2。Chrome 正在淘汰 MV2，后续需要迁移到 MV3（`setInterval` 后台计时要换成 alarms API，`getBackgroundPage` 也要一并调整）。

## 目录结构

```
healthyBreak/
├── manifest.json          # 插件清单（MV2）
├── background.html        # 后台页面，只挂载 background.js
├── popup.html             # 弹出面板：太阳、小鸭子、进度条、刷新按钮
├── js/
│   ├── background.js      # 核心：每秒计时、角标、通知、小鸭子体型状态
│   ├── popup.js           # 面板渲染与交互，直接读写后台页的状态
│   └── content-script.js  # 把屏幕分辨率发给后台，供弹窗自适应大小
└── img/                   # 小鸭子各状态图、图标
```

## 实现说明

- `js/background.js` 里一个 `setInterval(timer, 1000)` 就是全部的时间引擎：`count` 每秒自增，对 `cycleSeconds`（25×60）取模决定何时弹通知，超时则改角标颜色与文案。黑夜模式下 `count` 不增长，实现「时间停止」。
- `timer()` 返回本周期完成百分比，`js/popup.js` 拿这个值同时驱动小鸭子的横向位置和水位进度条宽度。
- 弹窗面板尺寸靠 `content-script.js` 上报的屏幕分辨率换算，因此需要网页上有 content script 注入过才能拿到准确数值。
- 小鸭子的胖瘦只存在内存里（`duckwidth` 变量），浏览器重启就回到初始大小——没有用 `storage` 持久化。
